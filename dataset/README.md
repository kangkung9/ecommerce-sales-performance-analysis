
# Dataset Information

## Dataset Name
Sample Superstore Dataset

## Source
[Kaggle - Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

## Dataset Description
This dataset contains retail transaction records from a fictional
superstore.

## Dataset Details
- Total Records: 9,994
- Period: 2014–2017
- Data Format: CSV

## Main Columns
- Order ID
- Order Date
- Customer ID
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit

## Purpose
The dataset is used to analyze sales performance,
profitability, customer activity, and regional performance.

Note: This is a sample dataset, not live business data.
